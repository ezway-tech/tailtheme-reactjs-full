## What’s included

- **Foundation** — colors, typography, radius, spacing, and visual style aligned with `src/styles/globals.css`
- **Variables** — collection `TailTheme / Theme` with **Light** and **Dark** modes
- **Components** — reference sets for primitives such as Button, Card, and Input
- **Patterns & examples** — documentation frames that mirror the in-app UI gallery (`/app/ui`)

## Using with the template

1. Open the Figma file (link above) if your access allows.
2. Inspect variables and components while customizing tokens in `src/styles/globals.css`.
3. Optional: wire Figma Code Connect stubs — see [`code-connect.md`](./code-connect.md).
   Builds and tests must not require a Figma token.

Component behaviour and live demos live under `/app/ui` and [`components.md`](./components.md).
Pixel-perfect parity between Figma and code is **not** claimed without a dedicated audit.
