# TailTheme React Lite — Agent Guide

## Scope

Minimal MIT starter generated from `tailtheme-reactjs-full` (`npm run sync:lite`).

## Rules

- Prefer PRs against **Full** for shared UI / tokens / patterns.
- Do not add purchase CTAs or locked features.
- Keep the starter small; pull extra components from Full when needed.

## Commands

1. `npm run typecheck`
2. `npm run lint`
3. `npm run test:run`
4. `npm run format:check`
5. `npm run build`
