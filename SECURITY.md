# Security Policy

## Supported versions

Security fixes are accepted against the default branch of this repository.

## Reporting a vulnerability

Please report security issues privately to the maintainers.

**Contact (maintainer to confirm):** `security@ezway.tech`  
If that address is not monitored yet, open a GitHub Security Advisory on the public repository once it is published, or contact the repository owners listed on GitHub.

Do not file public issues with exploit details before coordinated disclosure.
